# 🛡️ درع المدرسة — School Shield

حماية حواسيب الطلاب من المحتوى الإباحي والعنيف، بحيث **لا يستطيع الطالب بحساب Windows عادي إيقاف الحماية أو إزالتها**.

| | |
|---|---|
| 🟢 **الحماية مفعّلة** | الفلترة شغّالة وكل الفحوص ناجحة |
| 🟡 **جارٍ التحقق / غير مكتملة** | فحص لم يكتمل — لا ادعاء بالحماية |
| 🔴 **الحماية غير مفعّلة** | الفلترة متوقفة أو فشل فحص أساسي |

---

## ما الذي يتكوّن منه النظام

| الطبقة | الوظيفة | الملف |
|---|---|---|
| عميل Cloudflare One (WARP) مُدار | الحجب الفعلي عبر تصنيف محدَّث | يُثبّت من MSI رسمي |
| خدمة Windows دائمة | تعيد الفرض كل دقيقة وتكتب الحالة | `SchoolShieldService.exe` |
| واجهة الطالب | مؤشر واحد وزر واحد | `SchoolShield.exe` |
| أداة المدير | فحص، فرض، إيقاف مؤقت، إزالة | `schoolshield-admin.exe` |
| سياسات Registry | SafeSearch، YouTube مقيّد، تعطيل DoH | `policies.py` |
| تشديد ACL + جدار الحماية | منع الإيقاف وتجاوز الفلترة | `hardening.py` |

## التشغيل السريع

### ١. إعداد لمرة واحدة للمدرسة كلها
اتبع [`docs/SETUP-CLOUDFLARE.md`](docs/SETUP-CLOUDFLARE.md) — إنشاء مؤسسة Cloudflare Zero Trust وسياسات الحجب. **يجب إتمامه قبل تثبيت أي جهاز**، وإلا سيبقى المؤشر أحمر.

### ٢. البناء
```powershell
powershell -ExecutionPolicy Bypass -File build\build.ps1
```
المخرجات في `dist\`: `SchoolShield.exe`, `SchoolShieldService.exe`, `schoolshield-admin.exe`.

### ٣. التثبيت على جهاز طالب (كمدير Windows)
```powershell
powershell -ExecutionPolicy Bypass -File installer\install.ps1 -Organization "<اسم فريقك في Cloudflare>"
```
المثبّت ينفّذ كل شيء: نسخ الملفات، ضبط ACL، تثبيت عميل الفلترة مع `SWITCH_LOCKED=true`، تثبيت الخدمة وتشديدها، فرض السياسات، إنشاء حساب المدير، ثم **الفحص الحقيقي**.

### ٤. ملف تثبيت موحّد للتوزيع (اختياري)
ثبّت [Inno Setup 6](https://jrsoftware.org/isdl.php)، عدّل `OrgPlaceholder` في `installer\SchoolShield.iss`، ثم:
```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\SchoolShield.iss
```
المخرج: `installer\Output\SchoolShield-Setup.exe` — ضعه بجانب `website\index.html` على أي استضافة.

## حساب المدير

- اسم المستخدم الافتراضي: **`admin`**
- كلمة المرور الأولية **تُدخل تفاعليًا أثناء التثبيت** — ليست داخل الكود ولا داخل ملف التثبيت.
- تُخزَّن كتجزئة **Argon2id** فقط، في `C:\ProgramData\SchoolShield\secure\admin.json` المحجوب عن حسابات الطلاب بـ ACL.
- **يُفرض تغييرها عند أول تسجيل دخول** (١٢ حرفًا، حرف كبير وصغير ورقم ورمز).
- قفل تصاعدي بعد ٥ محاولات فاشلة (دقيقة ← ساعة).

---

## أوامر المدير

```powershell
schoolshield-admin verify              # الفحوص السبعة، مخرَج عربي مفصّل
schoolshield-admin verify --json       # للأتمتة؛ رمز الخروج 0 = أخضر
schoolshield-admin status              # ملخّص سريع
schoolshield-admin enforce             # إعادة فرض كل السياسات الآن
schoolshield-admin setup-org <org>     # ربط الجهاز بمؤسسة وقفل المفتاح
schoolshield-admin pause --minutes 15  # إيقاف مؤقت موثّق
schoolshield-admin resume              # استئناف
schoolshield-admin change-password     # تغيير كلمة المرور
schoolshield-admin audit-log           # سجل التدقيق الإداري
schoolshield-admin uninstall           # إزالة إدارية كاملة
```
كل أمر يغيّر الحماية يتطلّب **كلمة مرور المدير + صلاحيات Administrator على Windows معًا**.

## الفحوص السبعة

| # | الفحص | أساسي؟ | طريقة التحقق |
|---|---|---|---|
| ١ | عميل الفلترة مثبّت ومتصل | ✅ | `warp-cli status` |
| ٢ | الجهاز مسجّل ضمن سياسة المدرسة | ✅ | `mdm.xml` + تسجيل العميل |
| ٣ | حجب الإباحية | ✅ | استعلام DNS حقيقي على نطاقات مصنّفة |
| ٤ | حجب العنف | — | استعلام DNS حقيقي |
| ٥ | البحث الآمن و YouTube المقيّد | — | CNAME + سياسات Registry |
| ٦ | المواقع التعليمية تعمل | ✅ | ٩ نطاقات تعليمية |
| ٧ | الطالب لا يستطيع التعطيل | ✅ | ٨ بنود: SDDL، ACL، switch_locked، العضوية… |

**قواعد الحكم:**
- أي فحص **أساسي** غير ناجح ⇐ 🔴 أحمر.
- فحص لم يكتمل = **«غير متحقق»**، لا يُحتسب نجاحًا أبدًا.
- **NXDOMAIN ليس حجبًا** — نطاق ميت لا يُعطي أخضر كاذبًا.
- الاختبار يقف عند طبقة DNS: لا يُفتح أي محتوى إباحي على الجهاز.

## الاختبار الإلزامي قبل التوزيع

> ثبّت على حاسوب واحد، ثم **سجّل الدخول بحساب طالب عادي** وجرّب بالترتيب:
> 1. إيقاف خدمة `SchoolShield` من `services.msc` ← يجب أن يُرفض.
> 2. إطفاء مفتاح عميل Cloudflare One ← يجب أن يكون مقفولًا.
> 3. إلغاء التثبيت من Settings ← يجب أن يُطلب UAC ويُرفض.
> 4. تغيير DNS من إعدادات الشبكة ← يجب أن يُرفض.
> 5. فتح موقع إباحي ← يجب أن تظهر صفحة الحجب.
>
> **إن نجح الطالب في أي خطوة، النظام غير جاهز للتوزيع.**

## ما يحتاج حسابًا خارجيًا أو جهاز Windows

| العنصر | الحالة |
|---|---|
| حساب Cloudflare Zero Trust | **مطلوب** — الخطة المجانية تكفي حتى ٥٠ جهازًا |
| سياسات Gateway (حجب، بحث آمن، YouTube مقيّد، أمان) | ✅ **مضبوطة** — ٤ سياسات |
| قفل مفتاح العميل ومنع مغادرة المؤسسة | ✅ **مضبوط** في بروفايل الجهاز |
| Device Management Protection (حماية إلغاء التثبيت) | ⬜ **باقية** — تحتاج عميل 2026.9.0.0+ (`docs/SETUP-CLOUDFLARE.md`) |
| تثبيت الخدمة وACL وجدار الحماية | يحتاج تشغيلًا فعليًا على Windows بصلاحيات مدير |
| اختبار «الطالب لا يستطيع التعطيل» | يحتاج حساب طالب حقيقي على جهاز مثبّت |

**لا شيء هنا يحتاج اشتراكًا مدفوعًا** في الحجم المدرسي المعتاد.

## الحدود المُعلنة بصراحة

اقرأ [`docs/SECURITY.md`](docs/SECURITY.md). باختصار:
- من يملك **Administrator** على Windows يستطيع في النهاية إزالة أي برنامج. الطلاب يجب ألّا يكونوا في مجموعة Administrators.
- لا فلتر يحجب 100% من المحتوى غير المناسب داخل المواقع المسموح بها.
- المتصفح لا يستطيع تشغيل ملف تثبيت تلقائيًا — موافقة UAC إلزامية.
- حجب VPN والبروكسي **تقييد وليس منعًا مطلقًا**.
