# نموذج الحماية وحدودها

وثيقة صريحة لما يضمنه هذا النظام وما لا يضمنه. اقرأها قبل التوزيع.

---

## ١. ما يمنعه النظام فعلًا (حساب طالب عادي)

| المحاولة | ما يحدث | الآلية |
|---|---|---|
| إيقاف خدمة `SchoolShield` | **يُرفض** (Access denied) | SDDL يمنح `BU/IU` قراءة فقط بلا `DT` |
| قتل الخدمة لو وصل إليها | **تعود خلال ٥ ثوانٍ** | `sc failure … restart/5000` |
| إطفاء مفتاح عميل الفلترة | **المفتاح مقفول** | `switch_locked=true` + `auto_connect=1` |
| إلغاء تثبيت البرنامج أو العميل | **يُطلب UAC ويُرفض** | تثبيت لكل الأجهزة + Uninstall protection |
| تعديل `mdm.xml` أو ملفات الإعداد | **يُرفض** | ACL: SYSTEM + Administrators فقط |
| قراءة تجزئة كلمة مرور المدير | **لا يرى المجلد أصلًا** | `secure\` بلا أي منح لمجموعة Users |
| تغيير DNS من إعدادات الشبكة | **يُرفض** | تعديل المحوّلات يحتاج صلاحيات مدير |
| تشغيل DNS-over-HTTPS في المتصفح | **معطّل ومقفول** | `DnsOverHttpsMode=off` تحت `HKLM\SOFTWARE\Policies` |
| استخدام DNS عام (8.8.8.8…) | **محجوب** | قواعد جدار حماية صادرة على المنفذ ٥٣ |
| إطفاء البحث الآمن | **مفروض** | `ForceGoogleSafeSearch` + `ForceYouTubeRestrict` + فرض Gateway عبر DNS |
| التصفّح الخفي للالتفاف على السياسات | **معطّل** | `IncognitoModeAvailability=1`, `InPrivateModeAvailability=1` |
| إغلاق نافذة البرنامج | **لا أثر** | الحماية في خدمة مستقلة عن الواجهة |
| إعادة تشغيل الحاسوب | **تعود الحماية** | `start= auto` + `auto_connect` |
| إرسال أمر تعطيل إلى الخدمة | **غير ممكن** | البروتوكول لا يملك أمر تعطيل أصلًا: `STATUS`/`VERIFY`/`ENFORCE` فقط، وعلى loopback |

## ٢. ما لا يستطيع النظام ضمانه — بصراحة

### أ. مدير Windows
**من يملك صلاحيات Administrator على الجهاز يستطيع في النهاية إزالة أي برنامج**، بما فيه هذا. لا يوجد حل برمجي على Windows يمنع ذلك منعًا مطلقًا، وأي ادعاء بالعكس غير صحيح.

**الإجراء المطلوب منك:** ألّا يكون الطلاب أعضاء في مجموعة Administrators. الفحص السابع يتحقق من هذا ويُسقط المؤشر إلى الأحمر إن وجد الحساب الحالي مديرًا.

### ب. تغطية الفلترة
- **لا حجب 100%**. التصنيف يغطّي الملايين من النطاقات ويُحدَّث باستمرار، لكن المحتوى غير المناسب **داخل** موقع مسموح (مثل نتائج بحث أو منشور في شبكة اجتماعية مسموحة) قد يمرّ.
- فحص الحجب في البرنامج يختبر عيّنة من النطاقات، لا الإنترنت كلّه.

### ج. VPN والبروكسي — تقييد لا منع مطلق
- نحجب فئة **Anonymizer**، ومنافذ VPN الشائعة (OpenVPN, WireGuard, IPsec, PPTP, DoT)، وعناوين DNS العامة المعروفة.
- **لكن** VPN يعمل على المنفذ ٤٤٣ عبر TLS لا يمكن تمييزه عن تصفّح عادي بالحجب الشبكي وحده. المنع الكامل يحتاج **AppLocker** أو **WDAC** (قائمة برامج مسموحة) على Windows Pro/Enterprise — موصى به ولم يُنفَّذ هنا لأنه قرار إداري واسع الأثر على المختبر كلّه.

### د. المتصفحات المحمولة والأنظمة البديلة
- متصفح محمول (portable) يُشغَّل من USB **يبقى خاضعًا لفلترة DNS** على مستوى الجهاز (لأن الفلترة في النفق لا في المتصفح)، لكنه قد يتجاوز سياسات Registry الخاصة بالمتصفح (SafeSearch، التصفح الخفي).
- الإقلاع من USB بنظام آخر يتجاوز كل شيء. عالِجه من BIOS: كلمة مرور + تعطيل الإقلاع الخارجي.

### هـ. ملف التثبيت والمتصفح
**لا يمكن لأي موقع تشغيل ملف تثبيت تلقائيًا على جهاز الزائر.** المستخدم يفتح الملف بنفسه ويوافق على UAC. هذا سلوك أمان Windows المقصود، ولا نحاول تجاوزه.

## ٣. إدارة الأسرار

| السر | أين يعيش | أين **لا** يعيش |
|---|---|---|
| كلمة مرور المدير | تجزئة Argon2id في `secure\admin.json` (ACL للمديرين) | ليست في الكود، ولا المثبّت، ولا سطر الأوامر، ولا السجل |
| `UNINSTALL_TOKEN` من Cloudflare | لوحة Cloudflare + مكان آمن عندك | ليس على أجهزة الطلاب |
| `AUTH_CLIENT_SECRET` (إن استُخدم) | وسط التثبيت الإداري | ليس في موقع التنزيل ولا في الملف الموزَّع |

ملف `mdm.xml` الذي يكتبه المثبّت يحتوي اسم المؤسسة وإعدادات القفل فقط — لا أسرار. (يتحقق من ذلك اختبار `test_mdm_contains_no_secrets`.)

## ٤. سلوك النظام عند فشل الفلترة

عند انقطاع خدمة الفلترة:
- الخدمة تكتشف ذلك خلال دورة واحدة (٦٠ ثانية افتراضيًا) وتحاول إعادة الوصل.
- المؤشر يصير **أحمر فورًا** — لا يبقى أخضر كاذبًا.
- **لا نقطع الإنترنت تلقائيًا**: قطع الشبكة يعطّل Veyon وخدمات المدرسة ويحوّل عطلًا بسيطًا إلى توقّف صف كامل. إن أردت سلوك «Fail closed» الصارم، فاضبطه كسياسة مُدارة من لوحة Cloudflare مع استثناء صريح لنطاقات المدرسة، لا من هذا البرنامج.

## ٥. الخصوصية

- لا يُرسل البرنامج أي بيانات إلى أي خادم تابع لنا — **لا يوجد خادم تابع لنا أصلًا**.
- سجلات التصفّح تبقى في حساب Cloudflare الخاص بمدرستك وحدها، وتخضع لسياسة الاحتفاظ التي تضبطها أنت.
- الفحص المحلي يستعلم DNS فقط، ولا يفتح أي صفحة إباحية على جهاز الطالب.
- `audit.log` يسجّل العمليات الإدارية (دخول، إيقاف مؤقت، إزالة) داخل المجلد المحمي.
